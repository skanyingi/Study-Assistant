# Notes to Exam-Ready

A beginner-friendly AI study assistant. Upload a lecture-notes PDF and get a summary,
a multiple-choice quiz with explanations, and a spaced-repetition study schedule
leading up to your exam date.

## Setup

1. `pip install -r requirements.txt`
2. Copy `.env.example` to `.env` and add your Gemini API key.
3. `streamlit run app.py`
